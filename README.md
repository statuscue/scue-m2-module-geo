## API

### Url
https://domain.name/rest/rest/V1/geo/city

### Available params

#### q - is required GET-query param
Put your city name here. Currently city name must be at least 2 symbols

#### lang - force translations
Available values: uk/ru. If nothing presented or key isn;t supporteable, ukrainian language will be used by default

## Headers
Send header Content-Type: applications/json to get response in json format
